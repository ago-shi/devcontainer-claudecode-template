作業を再開します。ワークスペース配下のメモリを読み込んで前回の文脈を把握してください。

## 手順

1. `.claude/memory/MEMORY.md`（リポジトリルート直下）を読む。
2. インデックスに載っている関連メモリファイル（`.claude/memory/*.md`）をすべて読む。
3. 必要に応じて `git log --oneline -10` と `git status` を確認し、メモリの記載と実際のリポジトリ状態にズレがないか突き合わせる（メモリが古い場合は実態を優先する）。
4. 以下を簡潔にまとめて報告する：
   - **現在地**：直近で完了したこと
   - **次の作業候補**：順当な次フェーズ
   - **未決論点 / 残作業**：あれば列挙
5. 「どこから再開しますか？」とユーザーに確認する。

メモリの種類・保存先のルールは `CLAUDE.md` の「セッション記憶（Memory）」セクションに従うこと。
